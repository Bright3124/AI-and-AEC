About Me

I am a structural engineering designer focused on bridging the gap between traditional architectural and engineering practices and the next generation of AI tools. My work revolves around project design, coordination meetings, and finding ways to work smarter, not harder.

From sizing wood posts and designing reinforced concrete shear walls to managing complex code requirements (ASCE, ACI, AISC), I leverage AI and automation tools like Microsoft Power Automate to streamline workflows, allowing for more focus on critical design analysis.

AEC Use Cases & Projects

Structural Engineering Assistant

A custom AI agent configured specifically for structural designers. It acts as a rapid knowledge base for code compliance, specifically trained to reference ASCE 7 and ACI 318.

Key Feature: The agent is programmed with a priority directive to first check internal resources via the SharePoint location (013200 Structural - Real Estate, Guides) before utilizing broader data. Test validation included specific prompts such as querying for minimum slab reinforcement limits.

Executive Time Management & Proposal Flow

An automated workflow utilizing Microsoft Power Automate to generate daily briefings by parsing Outlook calendars and emails. This project also features an AI agent designed to assist management with drafting proposals across public safety, water/wastewater, and education markets.

Technical Detail: Utilized OData filter queries and precise data formatting to manage time zones effectively:

convertFromUtc(item()?['start'], 'Eastern Standard Time', 'hh:mm tt')

Project Powerlock

An experimental AI project stepping outside traditional AEC bounds. "Powerlock" is an agent designed to monitor live stock market trades, analyze the data stream, and generate calculated buy/sell notifications based on established parameters.

Learning Outcome: Advanced prompt engineering, live-data parsing, and decision-logic structuring.
